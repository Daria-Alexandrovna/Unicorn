## Что здесь

В этом репозитории находится решение первого домашнего задания по Python для анализа данных.

В ноутбуке `notebooks/hw1.ipynb` загружен индивидуальный участок данных ПРАЙМ, реализованы восемь расчётных задач на Python и подготовлены выводы по результатам анализа. Дополнительно выполнены исследования выборки и различий между сегментами.

## Как запустить

Нужны [Git](https://git-scm.com/) и [uv](https://docs.astral.sh/uv/).
Python отдельно ставить не нужно — его поставит uv.

```bash
git clone git@github.com:ВАШ_ЛОГИН/prime-monitor.git
cd prime-monitor
uv sync
```

Доступ к учебной базе выдаёт бот курса по команде `/db`. Полученную строку
подключения кладём в `.env`:

```bash
cp .env.example .env
# и вписать в .env строку из бота
```

Проверка, что всё встало:

```bash
uv run python -c "from prime.config import get_engine; print(get_engine().connect().execute(__import__('sqlalchemy').text('select current_user')).scalar())"
```

Запуск JupyterLab:

```bash
uv run jupyter lab
```
